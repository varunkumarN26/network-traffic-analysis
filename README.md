# 🌐 Network Traffic Analysis

## 📌 Project Overview

Hands-on project focused on understanding network communication, packet analysis and network reconnaissance using cybersecurity tools.

## 🛠️ Tools & Technologies

- Wireshark
- Nmap
- Kali Linux

## 🔍 Practical Activities

### 1. Packet Analysis – Wireshark
- Captured and analyzed network packets.
- Examined TCP/IP communication.
- Analyzed DNS and HTTP traffic.
- Explored network protocols and communication patterns.

### 2. Network Scanning – Nmap
- Performed network scanning.
- Identified open ports and services.
- Explored service discovery.
- Practiced network reconnaissance.

## 🎯 Technical Skills

- Network Traffic Analysis
- Packet Capture
- TCP/IP
- DNS
- HTTP
- Port Scanning
- Network Reconnaissance
- Network Security

## 📚 Learning Outcomes

Developed practical understanding of network protocols, packet analysis and network scanning techniques.

Educational project. Network testing should only be performed on authorized systems.
